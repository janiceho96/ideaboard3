IDEABOARD - DOWNLOAD, INSTALL, AND RUN

Download the project:
https://github.com/janiceho96/ideaboard3/archive/refs/heads/main.zip

Extract the ZIP before running anything. Open the extracted ideaboard3-main folder.

WINDOWS

1. Install Node.js 24 LTS with npm from https://nodejs.org/en/download.
2. Double-click launch-ideaboard.bat in the extracted project folder.
3. The first run downloads project packages; internet is needed for setup.
4. Ideaboard opens in your browser at:
   http://127.0.0.1:5174/ideaboard.html
5. Keep the command window open. Press Ctrl+C there to stop the local server.
6. Double-click the same launcher whenever you want to use Ideaboard again.

There is no Windows EXE/MSI installer yet. This is the browser version.
Core boards, notes, imports, and manual custom frameworks work in the browser.
AI generation and on-device OCR currently require the native Mac app.

If the launcher fails, open the extracted folder in File Explorer, type cmd in
its address bar, and press Enter. Run these commands in Command Prompt:

   node --version
   npm --version
   npm ci
   npm run dev -- --host 127.0.0.1 --port 5174 --strictPort --open /ideaboard.html

MAC DESKTOP APP

Building requires macOS 13 or later, Node.js 24 LTS/npm, full Xcode, and an Apple
Development signing certificate configured in Xcode.

1. Double-click macOS/install-ideaboard-mac.command in the extracted folder.
   If Finder blocks opening it, right-click the file and choose Open.
2. Or, from Terminal in the extracted project folder, run:
   zsh macOS/install-ideaboard-mac.command
3. Wait for installation, then open:
   Your Home Folder > Applications > Ideaboard.app
4. You can keep it in your Dock. No terminal, browser, Node.js, or Xcode is
   needed for everyday use after installation.

To update, quit Ideaboard and run the installer from the updated source folder.
It replaces the same app. Previous versions are saved as ZIPs in:
   ~/Library/Application Support/Ideaboard/App Backups

MAC BROWSER ALTERNATIVE

With Node.js installed, double-click launch-ideaboard.command. This opens the
browser version at the same browser address listed above. Keep its Terminal
window open and press Ctrl+C to stop it. It does not create another Mac app.

YOUR BOARDS AND BACKUPS

No sign-in is required. Work is saved locally. The Mac app and browser profiles
have separate workspaces, so keep using the same app/browser and address.

On the home screen, choose Export workspace backup to save your work as JSON.
To move between Windows, a browser, and the Mac app, export from the original
workspace, then choose Import workspace backup in the destination workspace.

FRAMEWORK DESIGN

Open Add Frame > Design a framework. Describe your goal, choose a visual shape,
and use Add Markdown or text to import your reference file, or select useful board
text. Preview and edit sections before saving.
A matrix needs four sections; other layouts have two to eight. You can design
manually on either platform. Design with AI requires the configured Mac provider.

In the Mac Board Assistant, select the Markdown file in Context, allow sharing,
then ask: "Use the selected Markdown to design a reusable custom framework with
4-6 sections and practical writing questions. Keep the sections empty."
Choose Edit & save framework on the resulting preview, review it, and save.

TROUBLESHOOTING

- Node/npm not found: install Node.js LTS and reopen the command window.
- Installation fails: check internet access and retry npm ci in the project folder.
- Port 5174 occupied: stop other Ideaboard command windows, then retry.
- Browser does not open: visit the address above while the launcher is running.
- Missing boards: check the app, browser profile, and address; use backup transfer
  when switching environments. Back up before clearing browser/app storage.
- Mac signing certificate missing: configure an Apple Development identity in
  Xcode; the installer preserves the existing app when prerequisites fail.
